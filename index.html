★ Featured Project

The Spot — Restaurant OS

A full restaurant management system with a public ordering menu, live kitchen dashboard, and admin panel. Built entirely solo with vanilla PHP, SQLite, JavaScript, and Tailwind CSS.

Why I built it: Most restaurant POS tools are either too expensive for small local restaurants or don't fit the way Nigerian food businesses actually operate — split billing, table-based ordering, cash-first workflows. I built this system from scratch to solve that gap. It handles live orders, kitchen queues, inventory tracking, staff roles, and billing entirely from the browser — no third-party dependencies.

About Minty

I'm Simeon (Minty) — a full-stack web developer and architect based in Lagos, Nigeria. I build web systems that solve real operational problems, from the database design up to the user interface.

My most complete project is The Spot — a full restaurant operating system I designed and built entirely solo. It handles live table orders, kitchen dashboards, inventory, staff roles, and billing. No framework, no team — just a problem I decided to solve.

My background in architecture gives me an edge most developers don't have — I think in systems, structure, and user flow before I write a single line of code. I'm currently open to remote developer roles and freelance projects where I can build something real.
