About Simeon

I'm Simeon David, a full-stack web developer and architect based in Lagos, Nigeria. I build web systems that solve real operational problems, from database design up to the user interface.

My most complete project is The Spot, a full restaurant operating system built entirely solo. It handles live table orders, kitchen dashboards, inventory, staff roles and billing, with no framework and no team.

My background in architecture gives me an edge most developers don't have: I think in systems, structure and user flow before writing a single line of code. I'm currently open to remote roles and freelance projects.
