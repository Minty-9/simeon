The Spot — Restaurant OS

A full restaurant management system with a public ordering menu, live kitchen dashboard, and admin panel. Built entirely solo with vanilla PHP, SQLite, JavaScript, and Tailwind CSS.

Why I built it: Most restaurant POS tools are too expensive for small local restaurants or don't fit Nigerian business workflows — split billing, table-based ordering, cash-first operations. I built this from scratch to solve that gap: live orders, kitchen queues, inventory, staff roles, and billing entirely in the browser, no third-party dependencies.

About Minty

I'm Simeon (Minty) — a full-stack web developer and architect based in Lagos, Nigeria. I build web systems that solve real operational problems, from database design up to the user interface.

My most complete project is The Spot — a full restaurant operating system built entirely solo. It handles live table orders, kitchen dashboards, inventory, staff roles, and billing, with no framework and no team.

My background in architecture gives me an edge most developers don't have — I think in systems, structure, and user flow before writing a single line of code. I'm currently open to remote roles and freelance projects.
